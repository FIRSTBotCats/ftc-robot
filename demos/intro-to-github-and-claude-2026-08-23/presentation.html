Version control = save points

Like a video game: every time you beat a level, you save.

Mess up? Load the last good save. No progress lost.

It’s a time machine for your code.

Two names, don’t mix them up

Git vs GitHub

🧠 Git

The save engine on your computer. It remembers every version.

☁️ GitHub

The shared locker in the cloud where the whole team’s saves live together.

Git = the save button. GitHub = the group chat for your code.

The unit of saving

A commit = a checkpoint

Each commit has a little message saying what you did.

✗ Useless

“stuff”

“asdf”

“fixed it”

✓ Helpful

“Slow down arm motor”

“Fix auto-drive turn”

Future-you reads these. Be nice to future-you.

The team loop

4 steps, that’s it

⬇️ Pull→ ✏️ Edit→ 💾 Commit→ ⬆️ Push

Pull = grab teammates’ latest. Push = share yours.

Golden rule: pull before you start.

🌿

Branches = a safe sandbox

Want to try a wild new auto routine?

Make a branch. Break stuff freely.

The robot that already works stays safe on main.

Code is read way more than it’s written

You write a line once.

You (and your teammates) read it a hundred times.

Write for the reader. Usually that reader is future-you at 11pm.

Best practice #1

Name things like a human

✗ From OUR robot

DcMotor m3; Servo s1; if (d.id == 20)

✓ After cleanup

DcMotor shooterMotor; Servo loaderServo; if (d.id == GOAL_TAG_ID)

What’s m3? What’s tag 20? The name should tell you — no treasure hunt.

Best practice #2

Comment the why, not the what

// ✗ pointless: code already says this shooterMotor.setPower(0); // set power to 0 // ✓ useful: explains the reason shooterMotor.setPower(0); // don't shoot unless the camera sees the goal tag
🐜

Small changes, one at a time

Change one thing → test → commit.

If something breaks, you know exactly what did it.

Giant “changed everything” commits = giant headaches.

Meet your teammate

What is Claude Code? 🤖

An AI that reads your code, and can write and change it —

while you watch and approve every step.

🧑‍✈️ You are the engineer in charge. Claude is the intern. A grown-up is signed in and supervising. Never run something you don’t understand — ask what it does first.
How to work with it

Good teammate, not magic button

  • 🎯 Be specific: “Make the arm stop at the top” beats “fix it.”
  • 🔍 Always read what it writes. Does it make sense?
  • 🧪 Test it on the robot before you trust it.
  • ❓ Ask “why did you do that?” — it’ll explain.
